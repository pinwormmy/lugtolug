# Row data fixes found during the reference cleanup (2026-10-28)

While checking references, the research also compared each row's stored figures with its sources and the brand. Only corrections backed by a stated figure were applied; each changed row's first source note now records the old value and the reason.

## Corrected figures (85 rows)

- Lug-to-lug: misread values replaced (case length or width imported as lug-to-lug, e.g. Depancel 7400, RGM 7268, Hautlence horizontal cases 7273/7281/7428/7439, Cuervo y Sobrinos 6987, Formex Baby Reef 2893, Zelos 5041, Gruppo Gamma PN-19 5715, Tissot PRX 35 6477 under the effective-length rule) and brand figures where they differ (Boldr, Naoya Hida, Temporal Works, Staudt, Romain Gauthier).
- Case size: bezel or overall width stored as the case (Unimatic 5504–5507, Nodus 6253, Vianney Halter 7270/7352, Depancel 8177/7246), and wrong-generation sizes (Omega 2984, Timex 2990, Mr. Jones 2993, Ikepod 7066, Christopher Ward 8183, Apple 6635 and others).
- Thickness: missing values filled from the sources, and figures that excluded the crystal replaced by overall height (Airain, Albishorn, Maen, Straum, Traska, Nivada, Brellum).
